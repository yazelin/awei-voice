# 原願望與兩個延伸專案的缺口盤點

## 結論

`mandarin-taigi` 與 `taigi-news-reader` 都提供了重要經驗，但沒有任何一個單獨符合阿瑋的五項期望。本 repo 已補上獨立網頁、文件匯入、雙語路由、預填的匿名限額服務與線上國語備援；仍未補齊的是台語母語者品質驗收、漢字台文直接朗讀、MMS 商用授權與服務 SLA。因此只能稱「功能已上線、台語 Beta」，不能把「正宗」視為已完成。

## 覆蓋矩陣

| 原始期望 | mandarin-taigi | taigi-news-reader | awei-voice 現況 |
|---|---|---|---|
| 文字轉語音 | 部分：官方單詞音檔＋裝置國語 fallback，不是任意句子 TTS | 部分：繁中新聞／短文轉台語再 TTS | 已上線：裝置 `zh-TW` 優先、edge-tts 線上備援、華語→POJ→MMS、POJ 直讀 |
| 國語／台語切換 | 沒有同一段文字的雙語模式 | 只有台語路徑 | 已上線：同頁切換；台語另分華語翻譯與 POJ 直讀，失敗不降級國語 |
| 簡潔大字網頁 | 有可參考的 PWA 與大字樣式，但產品是查詞 | 大字播放控制在 Chrome 側邊欄，不是獨立網頁 | 已上線：獨立 RWD PWA、鍵盤及文字標籤操作 |
| 輸入文字／上傳文件 | 只有查詞輸入，無文件匯入 | 可編輯擷取文字，無專用貼文／上傳入口 | 已上線：文字框＋TXT／MD／PDF／DOCX 瀏覽器解析 |
| 離線或低網速 | App shell、詞庫與已載音檔可離線，但不是任意 TTS | 可自架／暫存／重播，但現有擴充依後端且不是完整離線產品 | 已上線逐段與 IndexedDB；線上新合成仍需網路，本機離線需另裝完整模型 |
| 「正宗」可驗收 | 教育部單詞音檔來源可信，但不等於自然句子 | nan TTS；翻譯與自然度仍待母語者驗收 | 尚未完成：已揭露 provider／POJ／授權，但母語者試聽門檻未通過 |

## 可重用的經驗

### mandarin-taigi

- App shell 與資料／音訊 cache 分開管理的 PWA 原則。
- 文件與畫面誠實區分教育部原音、裝置語音與缺少音檔的做法。
- 大字、高對比、離線狀態、儲存空間提示與不宣稱永久保存的文案經驗。
- 教育部資料與音檔是 CC BY-ND 3.0 TW，不能因程式碼 MIT 就任意改作；第一版不直接複製資料包。

注意：該 repo 的 Service Worker 有多套 release 常數，必須抽象後重寫，不原封照搬。

### taigi-news-reader

- 文字正規化與自然標點分段。
- 非同步 synthesis job：建立、輪詢、取消、一次性取回與錯誤邊界。
- provider contract、POJ 白名單、MMS 真台語 TTS 與「失敗就失敗，不降級國語」原則。
- 本機重播的 IndexedDB、容量上限、TTL／清除與隱私資料流設計。
- FastAPI 本機／託管模式、endpoint／token 安全與模型授權揭露。

注意：現有 backend CORS 與 identity 為 Chrome 擴充套件設計；網頁版必須用精確 web origin 重新包裝。`facebook/mms-tts-nan` 是 CC BY-NC 4.0，只能作非商用參考，不能當成未設限的公共商用服務。

## 已補上的規格缺口

- 獨立網頁導覽與狀態機。
- 國語裝置 voice 選擇、線上非官方備援與台語 provider 能力偵測。
- PDF／DOCX 等文件的瀏覽器端解析與錯誤處理。
- 低網速逐段生產／播放、重試、取消與音訊持久保存。
- PWA 離線殼，以及「裝置語音／本機後端／省流量服務」三種能力的精確說明。
- 網頁 origin 的後端包裝、匿名 quota、隱私政策、第三方授權與部署文件。
- 台語母語者試聽表與正式品質門檻（規範已建立，真人執行尚未完成）。

## 仍然存在的缺口

- 120 句、至少 3 位母語者的正式試聽尚未完成，不能宣稱自然、正宗或特定台灣腔。
- `facebook/mms-tts-nan` 採 CC BY-NC 4.0，production Beta 不是一般商用方案。
- 非官方 edge-tts 線上備援沒有本專案可承諾的 SLA，也不保證服務或聲音長期不變。
- 漢字台文目前不能不經翻譯直接朗讀；直接模式只接受符合 MMS 字表、使用調符的 POJ，不接受數字調號。
- 匿名公開服務受共用 quota、主機容量及第三方 provider 可用率限制。
- PWA 離線只涵蓋 App shell、文件解析、已驗證裝置 voice 與已保存音訊；不涵蓋任意新線上合成。
