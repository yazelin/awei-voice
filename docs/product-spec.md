# 阿瑋好聲音：產品規格

- 日期：2026-07-21
- 願望池：#26「正宗台灣國語與台語語音系統（網頁版）」
- 狀態：可開始實作；仍需台語母語者完成語音品質驗收

## 目標

讓視力不佳、閱讀吃力的長輩，在一個大字、少步驟的網頁裡貼上文字或匯入文件，選擇台灣國語或台語後直接聆聽。網路不穩時要逐段產生、逐段播放並保存已產生的語音；沒有外網時仍可開啟網頁，使用裝置聲音、本機語音服務或重播已保存的內容。

## 使用者

- 視力不佳、閱讀長文吃力，但能按大按鈕的長輩。
- 想聽台語內容的一般使用者。
- 協助長輩安裝 PWA、下載離線模型或設定語音服務的家人。

## MVP 範圍

### 1. 文字與文件輸入

- 可直接輸入或貼上繁體中文，最多 30,000 字。
- 可匯入 UTF-8 純文字、Markdown、PDF、DOCX，單檔最多 10 MiB。
- 文件在瀏覽器內解析；畫面先顯示抽出的文字、字數與檔名，使用者確認後才朗讀。
- 掃描型 PDF、圖片 OCR、加密 PDF、複雜表格與簡報不在第一版範圍；解析不到文字時要說明原因。

### 2. 國語／台語雙語切換

- 「台灣國語」讀取原文，只使用裝置列為 `zh-TW` 的聲音；沒有這類聲音時不得自動選 `zh-CN`。畫面必須顯示實際 voice 名稱，並說明 `zh-TW` 標籤不等於跨裝置品質或離線保證。
- 「台語」優先使用裝置真正列為 `nan-TW`／Taiwanese Hokkien 的聲音；否則使用設定好的台語後端。
- 台語後端可把一般繁體中文轉成口語台語羅馬字，再交給真正的台語／Min Nan TTS；回傳的台語稿與 provider 名稱可查看。通過母語者門檻前只能稱 Beta，不可預設宣稱自然或正宗。
- 台語失敗時顯示失敗原因，不得用台灣國語聲音冒充成功。
- 第一版不做同一句自動混用兩種語言，也不做語音辨識、聲音複製或角色配音。

### 3. 長輩優先的播放介面

- 主要字級至少 20 CSS px，主要按鈕高至少 56 CSS px，文字標籤清楚且焦點可見。
- 首屏只保留：輸入／匯入、語言、連線方式、開始朗讀。
- 播放時提供暫停、繼續、停止、上一段、下一段與 0.75×／1×／1.25× 語速。
- 顯示目前段落、總段落、處理中／播放中／已暫停／錯誤狀態；狀態不可只靠顏色。
- 鍵盤與螢幕閱讀器可以完成完整流程，尊重 `prefers-reduced-motion`。

### 4. 連線方式與離線語意

介面提供三種可理解的方式，並在選擇前顯示實際能力：

1. **裝置語音（可能離線）**：使用瀏覽器列出的系統語音。台灣國語通常可用；只有偵測到真正台語 voice 時才開放任意台語朗讀。選單揭露 `localService` 狀態；非本機 voice 可能由平台送往其供應者，即使本機 voice 也需實際斷網驗證。
2. **本機離線服務**：連到 `localhost`／`127.0.0.1` 的台語後端。模型與翻譯器完成一次下載後，合成時不需要外網；需由家人先安裝。
3. **省流量服務**：連到使用者選定的 HTTPS 後端。文字切成最多 280 字的段落，只產生即將播放的段落，成功後保存語音，重播不再耗流量。

PWA App shell、文件解析與已保存語音在斷網時可用。瀏覽器儲存可能被使用者或系統清除，畫面與文件不得宣稱永久保存。

### 5. 隱私與資料保存

- 無廣告、無追蹤、無 analytics。
- 文件與完整原文預設只留在目前分頁記憶體。
- 後端只收到使用者開始朗讀後、當下需要合成的文字段落與語速。
- endpoint 可持久保存；Bearer token 只保存於本次分頁，關閉後消失。
- 產生的台語音訊只在使用者選擇保存後寫入 IndexedDB；可逐筆刪除、全部清除與查看估計容量。
- README 與設定畫面揭露真正的 translator、TTS provider、授權、費用與資料處理者。

## 主要流程

1. 使用者開啟網頁，看到大字文字框與「匯入文件」。
2. 輸入／匯入後，畫面顯示可朗讀文字與字數。
3. 選「台灣國語」或「台語」，再選裝置語音、本機離線服務或省流量服務。
4. 系統在開始前檢查能力：聲音是否存在、後端是否可連線、台語 provider 是否真為台語。
5. 使用者按「開始朗讀」。文字在本機分段；國語交給裝置聲音，台語則逐段送往選定後端。
6. 第一段完成就開始播放；下一段在背景準備。使用者可暫停、繼續、跳段或停止。
7. 使用者可保存已產生音訊供離線重播，也可下載單一音訊檔（若 provider 回傳可下載格式）。

## 可驗收需求

### R1：任意文字朗讀

- 1–30,000 字繁中可貼入；空白、超限與不可見控制字元有明確錯誤。
- 文字依自然段落與標點切分，不切斷 Unicode 組合字。
- 停止後不再播放或送出新分段。

### R2：文件匯入

- TXT、MD、文字型 PDF、DOCX fixture 可在瀏覽器抽出預期文字。
- 檔案不會因「選取」就傳到網路；測試可觀察開始朗讀前無 synthesis request。
- 不支援、過大、加密或無文字文件會顯示人能採取下一步的錯誤。

### R3：雙語不可混淆

- 國語只選 `zh-TW` 或使用者明確選定的聲音。
- 台語只接受 `nan-TW`／明確台語裝置聲音，或 health response 明列為台語的後端。
- 台語 provider 失敗時沒有任何國語 fallback。

### R4：低網速與離線

- 省流量模式每次最多送 280 字，第一段完成即可播放，不等待全文。
- 已保存段落用同一文字、語言、語速與 provider 重播時不呼叫網路。
- 安裝過 PWA 後，斷網可開啟、匯入文件與重播已存音訊；裝置 voice 只有在實際斷網試播成功時才計入離線能力，不能只依賴 `localService` 標籤。
- 本機後端 health 通過後，拔除外網仍可完成一段台語 smoke（前提是模型已下載）。

### R5：長輩與輔具操作

- 主要觸控目標至少 56×56，焦點順序符合視覺順序，無圖示限定操作。
- 以鍵盤完成主要流程；播放狀態由 `aria-live` 宣告但不重複洗版。
- 200% 縮放與 320 CSS px 寬度下無水平捲動或被遮住的主要控制。

### R6：台語品質與誠實標示

- 母語試聽集固定 120 句，涵蓋日常生活、姓名、台灣地名、日期、數字、外來詞、國台語混用與 100–300 字文章。
- 至少 3 位台語母語者各評可理解性與自然度 1–5 分；MVP 採用門檻為平均皆 ≥4，且無造成事實相反的讀法。
- 未通過的 provider 標為「實驗性」，不可使用「正宗」「已驗收」字樣。
- 畫面可查看 provider、台語稿與已知授權限制。

## 明確不做

- 語音轉文字、即時翻譯、電話助理。
- 聲音複製、名人聲音、兒童／戲劇角色聲線。
- 自動 OCR、完整電子書 DRM、付費牆繞過。
- 保證所有裝置都有離線台語 voice，或把需要首次下載模型說成零安裝。
- 未經母語者試聽就宣稱「正宗」。

## 仍需真人完成的驗收

技術規格已足以開工；唯一不能由自動測試取代的是台語母語者試聽。第一版可以標「實驗性台語」公開測試，但通過 R6 前不得宣稱台語品質已完成驗收。
