# 阿瑋好聲音：產品規格

- 日期：2026-07-21
- 願望池：#26「正宗台灣國語與台語語音系統（網頁版）」
- 實作狀態：網頁與匿名限額語音服務已上線；台語仍為實驗性 Beta，尚未完成母語者品質驗收
- 網頁：<https://yazelin.github.io/awei-voice/>
- 推薦後端：`https://ching-tech.ddns.net/awei-voice`

## 目標

讓視力不佳、閱讀長文吃力的使用者，在大字、少步驟的網頁中貼上文字或匯入文件，聽台灣國語，或把華語轉成 POJ 台語稿後產生台語音訊。低網速時採逐段產生與重播快取；離線時可使用已驗證的裝置 voice、已保存音訊，或由家人事先安裝完整模型的本機服務。

本規格中的「台語」只代表 provider 與資料流符合台語路徑，不代表自然度或腔口已驗收。通過 R7 前一律標示「台語 Beta」，不得宣稱「正宗」。

## 使用者

- 視力不佳、閱讀長文吃力，但能使用大按鈕的長輩。
- 想把華語內容轉成台語收聽的一般使用者。
- 已有符合 MMS 字表、使用調符的 POJ，希望直接產生台語音訊的使用者。
- 協助長輩安裝 PWA、本機模型或設定服務的家人。

## 已實作範圍

### 1. 文字與文件輸入

- 可輸入或貼上最多 30,000 字。
- 可匯入 UTF-8 純文字、Markdown、文字型 PDF、DOCX，單檔最多 10 MiB。
- 文件只在瀏覽器解析；匯入時不傳送原始檔、檔名或全文。
- 掃描 PDF、OCR、加密 PDF、複雜表格與簡報不在目前範圍。

### 2. 台灣國語

- 優先使用瀏覽器列出的 `zh-TW` 裝置 voice，不自動拿 `zh-CN` 冒充。
- 顯示實際 voice 名稱與 `localService` 狀態；標籤不等於離線或口音品質保證。
- 找不到裝置 `zh-TW` 時，可使用推薦後端的線上備援。
- 線上備援使用非官方 `edge-tts` client 與 `zh-TW` 線上聲音，需要網路，無本專案保證的 SLA。

### 3. 台語 Beta

台語提供兩個明確分開的來源：

1. **華語翻成台語**：`source_language=zh-TW`、`target_language=nan-TW`。推薦後端把華語分段送到 Groq 轉成 POJ，再由部署主機上的 `facebook/mms-tts-nan` 合成。
2. **POJ 調符直接朗讀**：`source_language=nan-Latn-TW`、`target_language=nan-TW`。輸入先在前端依 MMS POJ 字表正規化與檢查，再直接交給 MMS，不呼叫 translator；數字調號目前不支援。

目前不支援漢字台文直接朗讀。漢字輸入必須選「華語翻成台語」；系統不會把漢字直接標成 `nan-Latn-TW`，也不會在台語失敗後改播國語。

畫面會顯示 POJ 稿與實際 provider。Groq 翻譯與 MMS 發音都尚未通過母語者門檻，可能有語意、專名、數字、用詞、變調或腔口問題。

### 4. 長輩優先介面

- 主要字級至少 20 CSS px；主要按鈕高至少 56 CSS px。
- 輸入／匯入、語言、台語輸入類型、連線方式與開始朗讀都有文字標籤。
- 播放提供暫停、繼續、停止、上一段、下一段及 0.75×／1×／1.25×。
- 顯示目前段落、總段落、處理中／播放中／已暫停／錯誤狀態，且不只依賴顏色。
- 鍵盤與螢幕閱讀器可完成主要流程；尊重 `prefers-reduced-motion`。

### 5. 連線方式

1. **裝置語音（可能離線）**：只直接朗讀原文；不負責華語翻台語。是否離線由平台決定。
2. **本機服務**：連到 `localhost`／`127.0.0.1`。本機 Ollama 與 MMS 完成首次下載後，可另外驗證斷網合成。
3. **省流量服務**：推薦網址預填為 `https://ching-tech.ddns.net/awei-voice`。每段最多 280 字，第一段完成就播放，下一段在背景準備。

匿名訪客可不填 token，但共用服務端配額；個別邀請碼若有提供，只保存在本次分頁的 `sessionStorage`。

### 6. 離線與低網速語意

- PWA 外殼、已載入 parser 及已保存音訊可在完成快取後離線使用。
- 裝置 voice 只有實際斷網試播成功才算離線。
- 推薦後端、Groq 與 edge-tts 都需要網路；PWA 可離線開啟不等於任意新文字可離線合成。
- 使用者可選擇把成功產生的音訊保存至 IndexedDB；同一文字、路徑、provider 與語速命中快取後不再請求網路。
- 瀏覽器可能驅逐站台資料，不能宣稱永久保存。

### 7. 隱私與第三方處理

- 無廣告、analytics、telemetry 或追蹤像素。
- 只有按下朗讀後才傳送當下分段。
- 華語翻台語時，Groq 收到華語分段；MMS 在部署主機收到 POJ。
- POJ 直讀不呼叫 Groq；線上台灣國語的第三方語音服務收到國語分段。
- endpoint 可保存在 `localStorage`；Bearer token 只存 `sessionStorage`。
- 完整資料流見 [`PRIVACY.md`](../PRIVACY.md)，模型與套件授權見 [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md)。

## 主要流程

1. 使用者輸入文字或匯入文件。
2. 選台灣國語時，系統先偵測裝置 `zh-TW`；找不到時可改用預填的線上服務。
3. 選台語時，使用者明確選「華語翻成台語」或「POJ 調符直接朗讀」。
4. 省流量服務的推薦網址已填入；一般匿名使用不需 token。
5. 按下「開始朗讀」後才逐段送出；第一段完成立即播放。
6. 台語畫面顯示 POJ 與 provider；錯誤時停止，不以國語 fallback。
7. 使用者可保存成功音訊供之後重播或自行刪除。

## 可驗收需求

### R1：文字與文件

- 1–30,000 字能按自然標點分段；空白、超限與控制字元有明確錯誤。
- TXT、MD、文字型 PDF、DOCX fixtures 能在瀏覽器抽字。
- 開始朗讀前沒有 synthesis request；停止後不再送出新分段。

### R2：台灣國語路由

- 裝置模式只列 `zh-TW`，無聲音時有可採取下一步的線上備援。
- 線上服務 health 必須揭露 `mandarin_synthesizer`、需要網路、非官方與無 SLA。
- 國語線上結果的 provider 與 health 宣告一致。

### R3：台語路由不可混淆

- 華語翻譯固定走 `zh-TW → nan-TW`，成功結果有 POJ、音訊與 provider。
- POJ 直讀固定走 `nan-Latn-TW → nan-TW`，不呼叫 Groq。
- `nan-Latn-TW` 在建立工作前拒絕漢字、數字調號與 MMS POJ 字表外字元。
- 台語失敗時沒有國語 fallback。

### R4：公開服務與憑證

- 推薦 endpoint 由正式 build 設定，且只接受 HTTPS 遠端網址。
- Production 空 token 進匿名共用 quota；若另一個部署啟用邀請制，缺少或錯誤 token 必須拒絕。
- token 不進 `localStorage`、URL、bundle、log、Service Worker 或音訊 cache。
- Origin gate、邊緣限流與服務端 durable quota 都需生效；匿名不代表無限額。

### R5：低網速與離線

- 每段最多 280 字；第一段完成即可播放，不等待全文。
- 已保存段落命中相同路徑與 provider 時不連網。
- 斷網可開啟已安裝 App shell、解析本機文件與重播已存音訊。
- 本機模型完成下載後，另以拔除外網的 smoke 驗證本機台語生成。

### R6：可及性

- 主要觸控目標至少 56×56，焦點順序符合視覺順序。
- 鍵盤可完成匯入／輸入、選擇、開始、暫停、繼續、停止。
- 200% 縮放與 320 CSS px 寬度下無被遮住的主要控制。

### R7：台語品質與誠實標示

- 固定 120 句，至少 3 位台語母語者評可理解性與自然度。
- 兩項平均皆 ≥4.0，且姓名、日期、金額、地點與事實不得有反轉性錯誤。
- provider／translator／模型或 prompt 版本改變時重新抽驗。
- R7 尚未完成；在此之前只能標「實驗性」「Beta」，不可標「正宗」「已驗收」。
