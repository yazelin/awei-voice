# 台語母語者試聽規範

> 狀態：**尚未執行完成**。目前 Production 的 Groq→POJ→MMS 與 POJ→MMS 都只能標示「台語 Beta／實驗性」，不得標示「正宗」或「已驗收」。

## 為什麼自動測試不夠

POJ 字元白名單只能證明模型吃得下輸出，不能證明翻譯正確、變調自然、專名沒被唸成國語，也不能代表長輩聽得懂。「正宗」只有經過母語者在實際情境試聽後才有可驗收的意思。

## 採用門檻

- 至少 3 位平常會說台語的母語者。
- 固定 120 句測試集，每位都聽同一 provider／版本／rate=1。
- 每句評「可理解性」與「自然度」1–5 分，另記錯字、錯音、語意反轉與偏好腔口。
- 兩項平均都至少 4.0。
- 不得有造成姓名、日期、金額、地點或事實相反的嚴重錯誤。
- 未通過的 provider 只能顯示「實驗性」，不可顯示「已驗收」或「正宗」。

兩條台語 route 要分開評：

- `zh-TW → Groq POJ → MMS`：同時評翻譯語意、POJ 與最終發音。
- `nan-Latn-TW POJ → MMS`：使用固定人工校對 POJ，只評 TTS 可理解性、自然度與腔口。

線上台灣國語的 edge-tts 備援不是台語 provider，不納入台語門檻；其非官方來源與無 SLA 限制也不能由試聽分數消除。

## 測試集配置

| 類型 | 句數 | 必含內容 |
|---|---:|---|
| 日常生活與語助詞 | 24 | 問候、吃飯、天氣、交通、看病、連讀變調 |
| 數字與格式 | 18 | 日期、時間、金額、電話、地址、百分比 |
| 台灣人名與地名 | 18 | 常見姓氏、三字姓名、行政區、廟宇、市場 |
| 多音與專名 | 18 | 漢字多音、品牌、外來詞、縮寫、科技詞 |
| 國台語夾雜 | 18 | 自然語碼混用與全台語讀法分開評分 |
| 長段落 | 24 | 100–300 字生活、公告、新聞與醫療提醒 |

## 執行紀錄

每次評測保存：

- provider 與模型完整版本。
- translator、prompt／G2P 版本。
- route（華語翻台語或 POJ 直讀）及線上 endpoint release。
- 測試日期、裝置、瀏覽器、聲音速度。
- 每句輸入、產生的台語稿、音訊雜湊。
- 匿名 reviewer 編號、分數與備註。

不要把姓名、聯絡方式或完整個人資料放進公開 repo。對外只發布匿名彙整與已取得同意的問題樣本。

任何 translator、MMS checkpoint、prompt、文字正規化或語速 mapping 的實質變更，都要重新抽驗；只有自動測試通過或能成功出聲，不算母語品質驗收。
