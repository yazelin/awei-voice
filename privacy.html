文件先留在你的裝置

輸入、貼上或匯入的 TXT、Markdown、PDF、DOCX 都先在瀏覽器內解析。選取文件不會自動上傳；完整原文預設只存在目前分頁。

什麼時候會送出文字？

「裝置語音」不連本專案的自訂 TTS endpoint，但標為「可能需連網」的系統 voice 仍可能由瀏覽器、作業系統或其語音供應者處理文字；即使標成「裝置內」，也應實際斷網確認。只有選擇台語、本機服務或省流量服務，並按下「開始朗讀」後，本專案才會把當下需要合成的文字分段送到畫面上指定的 endpoint。省流量模式每段最多 280 字。

邀請碼與服務網址

服務網址可留到下次使用。Bearer 邀請碼只放在這個分頁的 sessionStorage，不會進入網址、Service Worker、音訊快取或永久儲存；關閉分頁後消失。

保存的台語語音

保存預設關閉。勾選後，音訊、台語稿、provider 與必要 cache metadata 會存到 IndexedDB；上限 50 MiB，採 7 天 LRU，可在首頁逐筆下載／刪除或全部刪除。瀏覽器或使用者仍可能清除這些資料。

不做什麼

本專案沒有廣告、analytics、telemetry 或追蹤像素，不建立使用者輪廓、不出售資料。遠端語音服務與 GitHub Pages 各有自己的資料處理政策。

問題與刪除

本機資料可在首頁或瀏覽器站台設定清除。問題可在 GitHub Issues 回報；Issue 是公開頁面，請勿貼文件全文、邀請碼、API key 或個人資料。
