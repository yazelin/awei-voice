匯入文件先留在你的裝置

輸入、貼上或匯入的 TXT、Markdown、PDF、DOCX 都先在瀏覽器內解析。選取文件不會自動上傳；原始檔、檔名與完整原文預設只存在目前分頁。

按下朗讀後會送到哪裡？

網站只有在你按下「開始朗讀」後，才傳送當下要播放的文字分段；省流量服務每段最多 280 字，不傳原始文件。裝置 voice 可能在本機處理，也可能由瀏覽器或作業系統送給其供應者，localService 標記不能取代實際斷網測試。

  • 華語翻台語：推薦後端會收到華語分段並送到 Groq 轉成 POJ；POJ 再由部署主機上的 MMS 產生音訊。
  • POJ 調符直讀：相容 POJ 直接交給部署主機上的 MMS，不呼叫 Groq；不接受數字調號，也不支援漢字台文直接朗讀。
  • 線上台灣國語：推薦後端會收到國語分段，再透過非官方 edge-tts 連接 Microsoft Edge 使用的線上語音服務。此路徑需要網路且沒有本專案保證的 SLA。

匿名配額、邀請碼與服務網址

推薦服務為 https://ching-tech.ddns.net/awei-voice，不要求邀請碼，匿名使用共用限額；服務網址可留到下次使用。若改連邀請制部署，Bearer token 只放在這個分頁的 sessionStorage，不會進入網址、程式 bundle、Service Worker、音訊快取、log 或永久儲存；關閉分頁後消失。

保存的語音

保存預設關閉。勾選後，音訊、必要朗讀稿、provider 與 cache metadata 會存到 IndexedDB；上限 50 MiB，採 7 天 LRU，可在首頁逐筆下載／刪除或全部刪除。瀏覽器或使用者仍可能清除這些資料。

離線能力的邊界

完成快取後，PWA 外殼、文件解析和已保存音訊可以離線使用；新產生的線上國語、Groq 翻譯與線上台語音訊仍需要網路。PWA 可離線開啟，不代表能離線產生任意新語音。

不做什麼

本專案沒有廣告、analytics、telemetry 或追蹤像素，不建立使用者輪廓、不出售資料。GitHub Pages、後端主機、Groq、Microsoft 相關線上語音服務與使用者自行指定的 provider 各有自己的資料處理政策。

問題與刪除

本機資料可在首頁或瀏覽器站台設定清除。問題可在 GitHub Issues 回報；Issue 是公開頁面，請勿貼文件全文、邀請碼、API key 或個人資料。
